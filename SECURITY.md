# Security Policy

This is an academic project (PFE). It is not intended for production deployment without a security review.

## Reporting a vulnerability

If you find a security issue, open a private GitHub issue or contact the repository owner directly via GitHub.

## Known scope

- No public-facing deployment exists.
- Credentials in `.env.example` are placeholders for local development only. Never use them in any deployed environment.
- The seed script creates accounts with predictable passwords — change them before any non-local deployment.
